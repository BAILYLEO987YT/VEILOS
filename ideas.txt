VEIL-MESH - giving the ability to create a mesh network of consumer grade computers to share resources and data. with multiple node types;
1. delegate nodes - a seperate device that stays seperate, takes: input data ie mouse/keybord or commands. returns: output data ie screen output or a response to a command. with an option to swap delegate nodes on the fly or on startup with a small gui or command line.
2. compute nodes - a direct piece of the cluster system, takes: batch proccesses or partial tasks. returns: completed batch data or completed partial tasks data.
3. offload nodes - a node thats directly part of the cluster system, takes: whole proccesses or tasks. returns: completed proccess or task data.
4. storage nodes - a node that directly part of the cluster system surrendering storage space to the cluster.
5. controller nodes - a director of the cluster system, managing and orchestrating the other nodes, the thing the user directly controls.
6. hub node - a device that behaves as a controller node for sub networks allowing the controller to send it a whole proccess and the hub to share it out amungst connected nodes in that sub network.

3 phase ledger - a ledger system allowwing for easy backups, rollbacks and recoveries of data and files in a 3 pronged approach. 
1. local directory ledger file, lists hashes of a user configured length of versions (ie 3,5,10 ect) of the files and directories inside the directory.
2. directory metadata ledger, an aditional part of the metadata of the directory that lists the last 3 versions of hashes of all files and directories that are in the directory above the current directory.
3. a system ledger file for the whole system, with a hash of root directory in each of the storage drives with versioning going back 10 times and user configuration for specific files or conditions, this system ledger is stored on the main drive.

custom v brand file types - allowing for the ability of files to be encrypted and decrypted nativley with levels of security the user can configure.
