# Design goals #

this os VEIL-OS is designed to be a custom software designed to have compatability with windows format alongside its own unique format.
the os should have the ability to switch between a secure mode with the prime focus of security from outside or internal threats to the system and or data. then switching to performance, which is a mode focusing on speed end effeciency so getting as close to bare metal speeds as possible.
the os should be customisable deep root style, so rather than just basic customisations such as colours and more advanced such as grouping and positioning but actual behaviours of the os.
