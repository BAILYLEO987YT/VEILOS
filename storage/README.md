VEILOS - Virtual Environment Integrated Lightweight Operating System

This is a test file for the VEILOS file explorer.

File Manager or using CAT README.TXT in the terminal.

Features:
- Custom 8x8 bitmap font rendering
- Window manager with drag and resize
- FAT16 filesystem driver
- Terminal emulator with shell commands
- File explorer with file viewing
